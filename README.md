# Vélin V11 Web

Version organisée pour un hébergement Internet statique (notamment GitHub Pages).

## Structure

- `index.html` : application Vélin
- `assets/audio/` : les 7 ambiances séparées du HTML
- `manifest.webmanifest` : métadonnées web/PWA
- `.nojekyll` : évite le traitement Jekyll sur GitHub Pages
- `404.html` : page d’erreur simple

## Mise en ligne

Déposer tout le contenu de ce dossier dans la racine d’un dépôt GitHub, puis activer GitHub Pages sur la branche `main`, dossier `/ (root)`.

## Important

Cette V11 Web reste une application principalement côté navigateur : les comptes et publications locales ne deviennent pas automatiquement une base de données publique. Un backend sera nécessaire pour la V12 multi-utilisateur.
